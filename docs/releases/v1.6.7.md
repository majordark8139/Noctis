# Noctis v1.6.7 — Windows 7 SP1 & Bit-Perfect Lossless Edition

This release introduces native **Windows 7 SP1 (64-bit)** support to Noctis alongside a completely revamped audiophile **Bit-Perfect WASAPI Exclusive Mode** playback pipeline and dedicated hardware lock management.

---

### 🌟 What's New & Highlights

#### 🎛️ Bit-Perfect WASAPI Exclusive Audio Engine
- **Direct DAC Hardware Transport**: Direct bit-perfect PCM audio stream via NAudio WASAPI Exclusive Mode that completely bypasses the Windows Audio Engine (`audiodg.exe`), software mixer, volume scaling, and OS resamplers.
- **Dynamic Hardware Sample-Rate Locking**: Automatically switches and locks your DAC hardware clock directly to the audio track's native sample rate (e.g. 44.1 kHz, 48 kHz, 88.2 kHz, 96 kHz, 176.4 kHz, 192 kHz).
- **Dedicated Hardware Stop Button**:
  - Added a dedicated **Stop** button across all playback interfaces:
    - Main bottom player bar (pill player)
    - Fullscreen lyrics view
    - Floating MiniPlayer popup menu
  - Halts playback and immediately resets progress to `0:00`.
  - **Full DAC Hardware Lock Release**: Explicitly disposes the exclusive audio sink and COM endpoints on stop, freeing the exclusive lock so other system applications (browsers, Discord, MusicBee, Spotify) can play audio without closing Noctis.
  - **Customizable Display**: Added a parent/child toggle tree under **Settings → Player → Player Island Buttons**:
    - *Stop button*: unconditionally show/hide across all interfaces.
    - *Only in Exclusive Mode*: optional child toggle to display the stop button only when exclusive mode is active to preserve player bar space.

#### 🪟 Full Windows 7 SP1 (x64) Native Compatibility
- **Self-Contained .NET 6 Runtime**: Fully ported and packaged with a self-contained 64-bit runtime. Runs out of the box on Windows 7 Service Pack 1 with zero external runtime prerequisites.
- **Avalonia SkiaSharp Per-Pixel Transparency**: Resolved black window borders and visual artifacts under the Windows 7 Desktop Window Manager (DWM).
- **Native Aero Glass Titlebar Integration**: Seamless glass framing with native Windows 7 Minimize, Maximize, and Close control buttons.
- **Bundled LibVLC 3.0.21 x64**: Includes official LibVLC 3.0.21 64-bit libraries for native offline decoding of FLAC, ALAC, WAV, APE, Opus, AAC, and MP3 without missing codec errors.
- **Deezer TLS 1.2 & Network Resilience**: Fixed TLS handshake failures on legacy Windows 7 crypto stacks to ensure artist metadata, cover artwork, and lyrics load seamlessly.
- **Extended Interface Scaling**: Added expanded scaling steps down to **50%** (50%, 60%, 70%, 80%, 90%, 100%, 110%, 120%, 130%, 140%, 150%) for ultra-dense displays or custom monitor resolutions.

#### 🎨 MiniPlayer & Interface Polish
- **Zero-Wedge Rounded Popups**: Applied Win32 round-rect region clipping (`CreateRoundRectRgn` with 36px radius) to the floating MiniPlayer menu, eliminating white square corner boxes on Windows 7 DWM while preserving full drop-shadow and zero text clipping.
- **Clean Button Tooltips**: Scoped popup overlay layers so hover tooltips across the playback bar (Shuffle, Play/Pause, Repeat, Previous, Next) remain crisp and borderless on repeated hover.
- **Fullscreen Restoration Fix**: Seamless transition when switching between F11 Fullscreen mode and MiniPlayer without leaving the application in borderless windowed limbo.
- **Audio Output Device Resilience**: Eliminated recursion crashes (stack guard page errors) in the audio device enumeration dropdown.

### 📦 Installation

#### Windows 7 SP1 (64-bit) Portable
1. Download `Noctis-v1.6.7-Win7-x64.zip` from Assets below.
2. Extract the archive to any folder (e.g. `C:\apps\Noctis` or `D:\apps\Noctis`).
3. Run `Noctis.exe`. No .NET installation or external codecs required!

#### Windows 10 / 11 / macOS / Linux
- Use the standard release installers or package managers (`winget install heartached.Noctis`).
