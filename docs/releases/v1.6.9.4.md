# Noctis v1.6.9.4 — Hotfix: Windows 7 yt-dlp & Add from YouTube Resolution

This is a targeted hotfix release for **Noctis v1.6.9** on Windows 7 SP1 x64, resolving the PyInstaller/Python `LoadLibrary: The specified module could not be found` error when searching or importing audio via **Add from YouTube** (`dev.noctis.plugins.youtubeimport`) and lyrics video backgrounds.

---

### 🛠️ What's Fixed in v1.6.9.4

#### 📥 Windows 7-Compatible yt-dlp Engine Integration
- **Resolved `Search failed — LoadLibrary: The specified module could not be found`**:
  - Upstream `yt-dlp` dropped support for Windows 7 / 8 in late 2024 and compiled standalone binaries with Python 3.10+ / PyInstaller that require Windows 10+ APIs, causing PyInstaller to fail extracting or loading `python3xx.dll` on Windows 7.
  - Automatically routes yt-dlp downloads to the dedicated Windows 7 / 8 compatibility builds (`yt-dlp_win7.exe`) maintained by `nicolaasjan/yt-dlp` when running on Windows 7 / legacy Windows (`OSVersion.Major < 10`).
  - Added legacy Windows detection and asset routing in both `Noctis.Plugins.YouTubeImport` and Noctis core's lyrics video service (`Noctis.Services.YouTube`).
  - Automatically cleans up any previously downloaded non-functional Windows 10 `yt-dlp.exe` on Windows 7 and seamlessly transitions to `yt-dlp_win7.exe`.

#### 🎰 Official Plugin Stability
- Both **Add from YouTube** (`dev.noctis.plugins.youtubeimport`) and **Album Roulette / Song Roulette** (`dev.noctis.plugins.albumroulette`) run smoothly on Windows 7 with bit-perfect integration into Noctis's native process.
- All .NET 6 `TimeSpan.FromSeconds(Int64)` and Avalonia 11 compatibility fixes are retained.

#### 🔄 In-App Updating (Direct Upgrade to v1.6.9.4)
- Users running **Noctis v1.6.9**, **v1.6.9.1**, or **v1.6.9.2** can update directly inside the app:
  1. Open Noctis on Windows 7 and navigate to **Settings → About**.
  2. Click **Check for updates**.
  3. Click **Install & restart**.
  4. Noctis will stage the package and cleanly replace the portable directory in-place, preserving your library, settings, and music folders.
