# Noctis v1.6.9.2 — Hotfix: Album Roulette, Song Roulette & Version Display

This is a targeted hotfix release for **Noctis v1.6.9** on Windows 7 SP1 x64, fixing the `TimeSpan.FromSeconds(Int64)` MissingMethodException in Album Roulette, enabling Song Roulette on the Songs page and Artist menus, and fixing the 4-digit version number display in Settings → About.

---

### 🛠️ What's Fixed in v1.6.9.2

#### 🎰 Album Roulette & Song Roulette Fully Functional
- **Fixed `Method not found: 'System.TimeSpan System.TimeSpan.FromSeconds(Int64)'`**:
  - In .NET 8 / 10, Microsoft added an overload `TimeSpan.FromSeconds(long)`. When upstream compiled Album Roulette v1.0.1, integer literals (`TimeSpan.FromSeconds(20)`) bound to this new overload, throwing `MissingMethodException` when executed on .NET 6.
  - Retargeted `Noctis.Plugins.AlbumRoulette` to `net6.0-windows` and updated all timer intervals to explicit double literals (`20.0`, `2.0`, `5.0`).
  - Added an in-process native factory in `PluginHost` for `dev.noctis.plugins.albumroulette`, guaranteeing that Album Roulette runs with 100% native .NET 6 type safety and zero CLR version/method mismatches.
- **Song Roulette Confirmation**:
  - **Song Roulette is an official feature of the Album Roulette plugin** (using Plugin API 1.7 `RegisterLibraryCommand`).
  - Because Album Roulette previously failed during `Initialize()`, the command buttons never had a chance to register.
  - Now that Album Roulette initializes cleanly:
    1. A **Song Roulette button** (musical note in a circle) appears directly in the **Songs page top bar** (beside the Shuffle button) to spin songs across your entire library.
    2. Both **Album Roulette** and **Song Roulette** appear in every **Artist page "…" options menu** to spin from that specific artist.

#### 🏷️ Accurate 4-Digit Version Display in Settings → About
- **Fixed "Version 1.6.9" Display**:
  - Previously, `UpdateService.CurrentVersionDisplay` and `DescribeBuild()` only formatted `{Major}.{Minor}.{Build}`, dropping the 4th revision segment (`{Revision}`). As a result, v1.6.9.1 showed up as "Version 1.6.9" despite being up to date.
  - Updated the version formatter to display the full 4-digit string (`Version 1.6.9.2`) whenever a hotfix revision is active.

#### 🔄 In-App Updating
- Can be installed directly via the in-app updater:
  1. Open Noctis on Windows 7 and navigate to **Settings → About**.
  2. Click **Check for updates**.
  3. Click **Install & restart**.
  4. Noctis will self-update in-place to **v1.6.9.2**.
