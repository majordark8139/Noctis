# Noctis v1.6.9.1 — Hotfix Release

This is a targeted hotfix release for **Noctis v1.6.9** on Windows 7 SP1 x64, addressing plugin loading compatibility for .NET 10 compiled plugins (Album Roulette & Song Roulette), missing artist portraits in the Similar Artists section, and validating the in-app portable self-updater engine.

---

### 🛠️ What's Fixed in v1.6.9.1

#### 🧩 Plugin Compatibility (.NET 10 & Avalonia 12 Unification)
- **Fixed `System.Runtime, Version=10.0.0.0` & `Avalonia.Controls, Version=12.1.3.0` Loading Crash**:
  - Plugins built upstream targeting .NET 10 and Avalonia 12 (such as **Album Roulette v1.0.1** and **Song Roulette**) failed to load in Noctis on .NET 6 with `Could not load file or assembly` exceptions.
  - Upgraded `PluginLoadContext` in `PluginHost.cs` to resolve host framework assemblies and abstractions by simple name directly to loaded host assemblies (`System.Runtime`, `Avalonia.Controls`, `Noctis.Plugins.Abstractions`), seamlessly bypassing CLR runtime version mismatches.
  - Added safe fallback type discovery in `PickPluginType` so unused reflection dependencies do not prevent valid `INoctisPlugin` instances from running.
  - **Album Roulette and Song Roulette now load and run flawlessly on Windows 7!**

#### 🖼️ Similar Artists Portrait Backfill & Deezer Image Delivery
- **Fixed Blank Gray Circles in Similar Artists**:
  - Resolved an issue where similar artists on the artist detail page (e.g. The Weeknd) showed blank placeholder circles if images weren't completely cached on the initial query.
  - `SimilarArtistsService` now automatically detects any cached artists with missing local image files and backfills their portraits asynchronously.
  - Enforced plain HTTP image fetching for Deezer CDNs (`cdn-images.dzcdn.net` / `e-cdns-images.dzcdn.net`) to prevent Windows 7 Schannel TLS 1.2 AES-GCM cipher suite handshake failures.
  - Added atomic image validation (`HttpSafety.LooksLikeImage`) and automatic directory creation.

#### 🔄 In-App Updater (In-Place Portable Self-Update)
- **Direct Update from v1.6.9**:
  - If you are running **Noctis v1.6.9**, you can update directly within the app:
    1. Open Noctis and go to **Settings → About**.
    2. Click **Check for updates**.
    3. Click **Install & restart**.
  - Noctis natively extracts `Noctis-v1.6.9.1-Win7-x64.zip` into staging and updates your portable directory in-place with zero installer wizard, zero Start Menu folders, and zero path changes!
