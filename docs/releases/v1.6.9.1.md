# Noctis v1.6.9.1 — Hotfix: Similar Artist Images

This targeted hotfix release for **Noctis v1.6.9** on Windows 7 SP1 x64 fixes the missing artist portrait images in the Similar Artists section and validates the in-app portable self-updater engine.

---

### 🛠️ What's Fixed in v1.6.9.1

#### 🖼️ Similar Artists Portrait Backfill & Deezer Image Delivery
- **Fixed Blank Gray Circles in Similar Artists**:
  - Resolved an issue where similar artists on the artist detail page (e.g. The Weeknd) showed blank placeholder circles if images were not cached on the initial query.
  - `SimilarArtistsService` now automatically detects any cached artists with missing local image files and backfills their portraits asynchronously.
  - Enforced plain HTTP image fetching for Deezer CDNs (`cdn-images.dzcdn.net` / `e-cdns-images.dzcdn.net`) to prevent Windows 7 Schannel TLS 1.2 AES-GCM cipher suite handshake failures.
  - Added atomic image validation (`HttpSafety.LooksLikeImage`) and automatic directory creation.

#### 🔄 In-App Updater (In-Place Portable Self-Update)
- Validated the in-app self-updater engine to extract and replace the portable installation directory in-place via native .NET 6 extraction and `robocopy` without installers.
*(Note: Full plugin loading compatibility and 4-digit version string display are finalized in v1.6.9.2).*
