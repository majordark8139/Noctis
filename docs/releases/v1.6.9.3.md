# Noctis v1.6.9.3 — Hotfix: Add from YouTube & Official Plugins Compatibility

This is a targeted hotfix release for **Noctis v1.6.9** on Windows 7 SP1 x64, fixing the `TimeSpan.FromSeconds(Int64)` `MissingMethodException` when enabling or running **Add from YouTube** (`dev.noctis.plugins.youtubeimport`), and applying a comprehensive compatibility unification across all official plugins.

---

### 🛠️ What's Fixed in v1.6.9.3

#### 📥 Add from YouTube Fully Compatible (.NET 6 on Windows 7)
- **Fixed `Method not found: 'System.TimeSpan System.TimeSpan.FromSeconds(Int64)'`**:
  - In .NET 8 / 10, Microsoft introduced an overload `TimeSpan.FromSeconds(long)`. When upstream compiled Add from YouTube v1.0.1, integer literals (`TimeSpan.FromSeconds(30)`) bound to this new overload, throwing `MissingMethodException` when executed on .NET 6 under Windows 7.
  - Retargeted `Noctis.Plugins.YouTubeImport` to `net6.0-windows` with `<SupportedOSPlatformVersion>7.0</SupportedOSPlatformVersion>` and updated all interval literals to explicit double precision (`30.0`, `2.0`, `3.0`, `250.0`, `500.0`, `24.0`).
  - Added an in-process native factory in `PluginHost` for `dev.noctis.plugins.youtubeimport`, ensuring that Add from YouTube runs with native .NET 6 type safety and immediate initialization without reflection version mismatch.

#### 🧩 Comprehensive Official Plugin Suite Compatibility
- **Universal Fix Across All Official Plugins**:
  - Along with Add from YouTube and Album Roulette, all official Noctis plugins have been retargeted to `net6.0-windows` and wired with native in-process factories:
    - **Add from YouTube** (`dev.noctis.plugins.youtubeimport`)
    - **Album Roulette & Song Roulette** (`dev.noctis.plugins.albumroulette`)
    - **A-B Loop** (`dev.noctis.plugins.abloop`)
    - **Album Town** (`dev.noctis.plugins.albumtown`)
    - **Chords** (`dev.noctis.plugins.chords`)
    - **True Shuffle** (`dev.noctis.plugins.trueshuffle`)
    - **Lyric Motion** (`dev.noctis.plugins.lyricmotion`)
    - **Mixxx** (`dev.noctis.plugins.mixxx`)
  - Any official plugin installed or enabled in Noctis now loads natively with zero CLR runtime mismatches or missing method exceptions on Windows 7 SP1.

#### 🔄 In-App Updating (Direct Upgrade to v1.6.9.3)
- Users running **Noctis v1.6.9**, **v1.6.9.1**, or **v1.6.9.2** can update directly inside the app:
  1. Open Noctis on Windows 7 and navigate to **Settings → About**.
  2. Click **Check for updates**.
  3. Click **Install & restart**.
  4. Noctis will stage the package and replace the portable directory in-place, preserving your library, settings, and music folders.
